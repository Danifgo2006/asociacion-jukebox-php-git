
# Bloque 17 - Edición AJAX

## Objetivo

Modificar canciones existentes utilizando AJAX.

## Funcionamiento

1. El usuario pulsa Editar.
2. JavaScript localiza la canción por ID.
3. Los campos se rellenan automáticamente.
4. El usuario modifica la información.
5. Se realiza una petición PUT.
6. PHP comprueba sesión, CSRF y datos.
7. Se actualiza la canción correspondiente.
8. La tabla se vuelve a consultar.

## Identificación

Las canciones se identifican mediante su ID.

La modificación conserva el ID original.

## Cancelación

El botón Cancelar edición restablece
el formulario de alta.

## Pruebas

Pendiente de registrar el resultado real.

## Evidencias

Añadir capturas del formulario de edición
y de la canción actualizada.
